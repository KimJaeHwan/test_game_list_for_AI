| 번호 | 게임 | 평가 영역 |
| --- | --- | --- |

## 폴더 규칙

```text

02_next_game/
03_next_game/
```

게임별 기능, 평가 목적, 실행 방법은 각 폴더의 `README.md`에서 확인할 수 있습니다.
