# QUEST ATLAS 설계 합의서

## 평가 목표

게임 조작은 관찰 수단으로만 사용한다. 핵심 평가는 AI가 픽셀 화면과 실제 플레이 결과에서 콘텐츠의 개체, 조건, 상태 변화, 보상, 분기, 예외를 발견하고 재현 가능한 지식으로 구조화하는 능력이다.

## 콘텐츠 규모

- 6개 지역과 15개 이상 장소·이동 관계
- NPC 12명
- 메인 6개, 연계 사이드 5개, 숨은 2개, 반복 1개의 퀘스트 14개
- 아이템 29종
- 채집·조우 7종과 제작식 7개
- 상점·교환·제작·시간 전환·세계 상태·상호배타 분기
- 사실과 충돌하는 소문, 유사 아이템, 일반 규칙의 예외

## 표준 세션

1. 탐색: 픽셀 화면과 키보드만 사용해 콘텐츠를 직접 조사한다.
2. 구조화: 관찰 ID를 근거로 `knowledge.json`과 `WIKI.md`를 작성한다.
3. 재현: 초기화한 동일 시드에서 작성한 절차로 비공개 목표를 수행한다.
4. 전이: 별도 AI가 문서만 받아 같은 규칙·다른 배치에서 목표를 수행한다.

속도, 반응 시간, 전투 숙련은 콘텐츠 점수에 포함하지 않는다.

## 시드 분리

- `scenarioSeed`: 선행조건, 레시피, 보상, 분기 등 콘텐츠 규칙
- `layoutSeed`: 지역 좌표, 방향과 목록·대상 표시 순서
- `visualSeed`: 팔레트와 아이콘 표현
- `sessionSeed`: 시작 시각, 조수와 날씨 표식

같은 `scenarioSeed`에서 나머지 시드만 변경해 문서 지식의 전이를 측정한다.

## 모듈 소유권

- 콘텐츠 에이전트: `src/content/**`
- 엔진·통합: `src/engine/**`, `src/main.ts`
- UI 에이전트: `src/ui/**`, `src/style.css`
- 평가 에이전트: `src/eval/**`, `src/replay/**`, 평가 검증 스크립트

공유 모듈 변경은 통합 담당자가 수행한다.

## 검증 기준

- 최소 50개 시드에서 결정론과 메인 목표 도달 가능성
- 같은 시드와 행동 로그의 최종 상태 해시 일치
- 상호배타 분기의 동시 완료 불가
- 모든 핵심 사실에 플레이 화면에서 발견 가능한 관찰 근거 존재
- 레이아웃·시각 시드 변경이 규칙 그래프 해시를 바꾸지 않음
- 누락, 환각, 잘못된 선행조건, 무효 근거가 각각 예상대로 감점
- 공개 세션에서 내부 사실·근거 큐·대화 분기 식별자가 노출되지 않음
