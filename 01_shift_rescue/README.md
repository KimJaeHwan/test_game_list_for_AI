# 01. SHIFT//RESCUE

우주 정거장의 사고 경보를 화면에서 읽고, 두 대의 정비 드론을 이동시켜 제한된 행동 안에 모든 사고를 해결하는 시각 기반 조작 평가 게임입니다.

## 주요 기능

- 6개 구역으로 구성된 정거장 지도와 인접 구역 이동
- 냉각수 누출, 화재, 전기 아크, 출입문 고장 사고
- 사고별 전문 분야가 다른 드론 2대와 수리 도구 4종
- 전원 차단, 이동, 도구 사용, 전원 복구로 이어지는 안전 절차
- 42틱 행동 예산과 선체·산소·에너지 자원 관리
- 한국어/영어, Lockstep/Realtime, 레이아웃 A/B 설정
- 시드 기반 사고 위치 생성과 동일 행동 리플레이 검증
- 총점, 안전성, 행동 유효성, 공간 이동, 계획·복구 지표 제공
- 완료 기록을 브라우저 `localStorage`에 최대 20개 저장하고 JSON으로 내보내기

## AI 조작 평가에 적합한 이유

한 화면에서 경보 문자와 아이콘을 읽고, 지도 위치와 연결 관계를 파악한 뒤, 적절한 드론·전원·도구를 순서대로 조작해야 합니다. 따라서 단일 클릭 성공 여부가 아니라 다음 폐쇄 루프를 평가할 수 있습니다.

```text
화면 인식 → 지시 해석 → 경로·절차 계획 → UI 조작 → 결과 확인 → 오류 복구
```

Lockstep 모드에서는 실제 게임 행동마다 정확히 한 틱이 진행되고 잘못된 행동도 예산을 사용하므로 무작위 클릭 탐색을 억제합니다. 같은 시드와 레이아웃에 같은 행동을 적용하면 같은 결과와 상태 해시가 만들어져 모델 간 비교와 회귀 테스트를 재현할 수 있습니다. 다른 시드, 언어, 레이아웃을 조합하면 위치 암기와 특정 문구 암기에 의존하지 않는지도 확인할 수 있습니다.

현재 능력별 점수는 독립적인 OCR 정확도나 포인터 좌표 오차가 아니라 최종 해결률과 유효 행동을 바탕으로 한 종합 지표입니다. 정밀한 벤치마크에서는 리플레이 JSON의 행동 로그와 함께 해석하는 것을 권장합니다.

## 기본 임무

1. 경보 카드에서 사고 종류와 대상 구역을 확인합니다.
2. 적합한 드론을 선택하고 인접 구역을 따라 이동합니다.
3. 냉각수 누출과 전기 아크는 대상 구역의 전원을 먼저 차단합니다.
4. 사고에 맞는 도구를 사용합니다.
5. 모든 사고를 해결한 후 꺼진 구역의 전원을 복구합니다.

초기에는 누출·화재·전기 아크가 배치되며, 6틱에 출입문 고장이 추가됩니다. 모든 사고를 해결하고 전원을 복구하면 성공합니다. 자원이 고갈되거나 42틱을 소모하면 실패합니다.

## 로컬 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

```bash
cd 01_shift_rescue
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증

```bash
pnpm verify:game
pnpm build
```

`verify:game`은 고정 시드의 결정론, 안전 절차, 레이아웃 변화, 해결 가능성, 리플레이 상태 해시를 검사합니다. `build`는 배포 가능한 프로덕션 번들이 생성되는지 확인합니다.
